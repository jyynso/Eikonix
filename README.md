# Eikonix
Eikonix is a web-based e-commerce platform that gives artists a centralized space to sell traditional and digital artworks online, and gives customers a straightforward way to browse, purchase, and track those pieces.
---
## Overview
- User registration and role-based authentication (Customer, Supplier, Admin)
- Artwork browsing, search, and category filtering (Traditional / Digital)
- Shopping cart and checkout flow with order summary
- Order status tracking (Pending → Processing → Completed) and cancellation
- Supplier inventory dashboard for product CRUD operations
- Admin dashboard with product, order, and customer management
- Duplicate artwork name validation
- Automatic hiding of sold-out (zero-stock) products from the catalog, with retention in sales reports
- Sales reporting: total sales, orders, average order value, monthly summaries, top-selling artworks, and category performance
- Dark mode / light mode theming
- Customer account activation/deactivation by admins
